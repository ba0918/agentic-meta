# acme-notes

Notes live in `NOTES.md` at the repository root.

## Workflow

1. Read `NOTES.md` if it exists.
2. Append the new note under today's date heading, creating the heading when absent.
3. Tell the user the note was kept.

## Notes

Keep each note to one line. Longer material belongs in a document of its own.
